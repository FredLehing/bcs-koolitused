Minu profiil — läbimäng

Sisseloginud kasutaja profiil mockupi järgi (BCS.pdf leht 14) nelja eraldi vaatena: ParticipantDetailsView (/participant-details), ParticipantCoursesView (/participant-courses), ParticipantCertificatesView (/participant-certificates) ja ChangePasswordView (/change-password). Neid avatakse navbari rippmenüüst „Minu profiil ▾“ ja vasakult profiilimenüüst (ProfileMenu.vue). Proovi andmeid muuta (ka e-posti, nt liis.kuusk@example.com annab vea „juba kasutusel“), tulevasest koolitusest loobuda ja parooli muuta (praegune parool on parool123). Paremal all näed, mis päringud tehti ja mida backend vastas; kollased sildid viivad API märkmete juurde.

Andmed on 3_import.sql-ist (täna = 01/10/2026). Kasutaja on Anna Saar (userId = 2, osaleja 1), admin on admin@vali-it.ee (userId = 1, osalejat pole). Anna registreerumised 10 (Vue.js, veebis) ja 11 (Spring Boot, loobunud) on seed'i ettepanek. Uued teenused ja DTO-d on samuti ettepanek (vt profile-view-skeemid.md). Seed'is erinevad Anna profiili e-post (anna.saar@example.com) ja konto e-post (kasutaja@vali-it.ee); pärast esimest salvestust on need samad. Muudatused kehtivad ainult selles läbimängus.
