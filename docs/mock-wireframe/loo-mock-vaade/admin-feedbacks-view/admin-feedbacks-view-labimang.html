Vaate märkmed ja andmete päritolu
  • Üks rida = feedback. Vastused = course_participant_feedback, kriteeriumide nimetused = feedback_criteria_translation.
  • Kõik toimumiskorrad, osalejad, registreerumiste ID-d, tagasisided ja vastused pärinevad 3_import.sql failist. Seis 01.10.2026: 30 tagasisidet, 150 vastust; Vali-IT Noorem AI arendaja 16/18 (88,9%), Agiilne meeskonnajuhtimine 4/5 (80%), Spring Boot 0/2 (0%). Loobunud ei kuulu nimetajasse.
  • Vaikimisi vajavad ülevaatust N ja U, siis H; iga grupi sees uuemad esimesena. Kõik staatused jäävad nähtavaks.
  • Vastamismäär kuvatakse ainult toimumiskorra valimisel. Nimetaja on registreerunute (R) arv, mitte tõendatud osalejate arv. Muud filtrid ei muuda selle kaardi lugejat ega nimetajat.
  • Kriteeriumid kuvatakse kasutajaliidese keeles, puuduva tõlke korral põhikeeles; kommentaare ei tõlgita. Ajalooliselt vastatud kustutatud kriteerium jääb nähtavaks.
