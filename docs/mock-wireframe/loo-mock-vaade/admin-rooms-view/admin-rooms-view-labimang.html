Koolitusruumid — läbimäng

AdminRoomsView.vue (koolitusruumide nimekiri) ja RoomFormView.vue (ruumi vorm: uus ruum ja muutmine). Otsi nime järgi, sorteeri veerge (1. klõps kasvav, 2. kahanev, 3. vaikimisi), ava ruum muutmiseks, lisa uus ruum, kustuta ja taasta („Näita kustutatud“). Paremal all näed, mis päringud tehti ja mida backend vastas; kollased sildid viivad API märkmete juurde.

Andmed on seed-andmete ettepanek (skeemide fail, jaotis 1): 6 ruumi. Assauwe — 2 tulevast toimumiskorda, prügikast keelatud; Bremeni — kustutatud („Näita kustutatud“), toimumiskorrad ainult minevikus. Proovi ka nime kordust (nt „eppingi“) — backend vastab 403 ROOM_NAME_EXISTS.

Detailide ja vormide avamisel säilib lähtevaate URL returnTo parameetris; „← Tagasi“ taastab lähtekoha. Tagasitee skeemid ja kaardistus.
