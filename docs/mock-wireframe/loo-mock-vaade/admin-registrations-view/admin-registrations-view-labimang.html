Registreerumised — läbimäng

AdminRegistrationsView.vue (kõigi registreerumiste nimekiri) ja AdminRegistrationView.vue (üks registreerumine). Otsi, sorteeri veerge (1. klõps kasvav, 2. kahanev, 3. vaikimisi), lülita sisse loobunud ja toimunud, ava registreerumine, muuda staatust, tasumist, sülearvutit või admini märkmeid ja salvesta. Paremal all näed, mis päringud tehti ja mida backend vastas; kollased sildid viivad API märkmete juurde.

Andmed on 3_import.sql-ist (täna = 01/10/2026): 9 registreerumist, neist 1 loobunud (Mari Lepp) ja 1 toimunud toimumiskorral (Anna Saar, september). Uus veerg admin_notes ja uute teenuste DTO-d on ettepanek (skeemide fail, jaotis 1). Muudatused kehtivad ainult selles läbimängus — teised läbimängud kasutavad oma andmeid.
