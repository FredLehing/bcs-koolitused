Koolituste kalender (admin) — läbimäng

AdminAllCoursesView.vue (kõigi koolituste toimumiskorrad) ja AdminCourseView.vue (üks toimumiskord koos osalejate ja huvilistega). Otsi, ava filtrid, sorteeri veerge (backendis: 1. klõps kasvav, järgmine vahetab suunda), lülita sisse möödunud, vaheta lehte, kustuta või ava toimumiskord. Paremal all näed, mis päringud tehti ja mida backend vastas; kollased sildid viivad API märkmete juurde.

Andmed pärinevad 3_import.sql failist ( täna = 01/10/2026): 16 toimumiskorda, neist 1 kustutatud ja 6 möödunud; 43 registreerumist (3 loobunud) ja 3 toimumiskorraga seotud päringut. Uute teenuste DTO-d on ettepanek.

Detailide ja vormide avamisel säilib lähtevaate URL returnTo parameetris; „← Tagasi“ taastab lähtekoha. Tagasitee skeemid ja kaardistus.
