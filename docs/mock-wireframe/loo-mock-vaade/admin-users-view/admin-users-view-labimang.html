Kontod — läbimäng

AdminUsersView.vue (kõigi kontode nimekiri) ja AdminUserView.vue (üks konto). Otsi, filtreeri rolli järgi, sorteeri veerge (1. klõps kasvav, 2. kahanev, 3. vaikimisi), lülita sisse deaktiveeritud, ava konto, deaktiveeri ja taasta. Enda kontot (admin@vali-it.ee, sisse loginud admin) deaktiveerida ei saa. Paremal all näed, mis päringud tehti ja mida backend vastas; kollased sildid viivad API märkmete juurde.

Andmed on 3_import.sql-ist (täna = 01/10/2026): 7 kontot, neist 2 adminit. Mari Lepal on ainult loobunud registreerumine. Uute teenuste DTO-d on ettepanek (vt admin-users-view-skeemid.md). Muudatused kehtivad ainult selles läbimängus.
